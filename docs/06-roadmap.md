# 6. Roadmap и backlog

Сроки и роли ниже — плановые предложения, не обязательства команды. Внешние согласования могут определять критический путь.

| Этап | Результат | Условие перехода |
|---|---|---|
| 0. Проверка спроса | Интервью с клиниками и МИС, наблюдение смены, описание проблемы | Найден сценарий, не закрытый штатной МИС; есть контакт владельца процесса |
| 1. Демо | Локальная очередь, терминал, врач, табло, тесты, документация | Сценарий трёх кабинетов проходит на тестовых данных |
| 2. Интеграционный PoC | Согласованный контракт МИС, sandbox, адаптер, синхронизация | Обновления записи и статусов воспроизводимы; конфликт не теряется |
| 3. Подготовка пилота | PostgreSQL, RBAC, защита сети, киоск, мониторинг, backup/restore, доступность | ИТ/ИБ и медперсонал согласовали регламент и критерии |
| 4. Пилот | Один участок, наблюдение до и после, отчёт | Измеримый эффект, нет ухудшения доступности или безопасности |
| 5. Тиражирование | Пакет установки, сопровождение, закупочная документация | Повторяемый результат и модель оплаты |
