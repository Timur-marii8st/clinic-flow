# 18. Протокол приёмки пилотного стенда

Выполняется на синтетических данных. Статус каждого пункта фиксирует ответственный с датой, версией, окружением и артефактом проверки. Не отмечать «пройдено» без измерения.

| Gate | Проверка | Критерий/ожидаемый результат |
|---|---|---|
| G01 | CI точного SHA | SQLite/PostgreSQL, browser, SSE, QR, роли, routing, миграции, backup — зелёные; предупреждения рассмотрены |
| G02 | Функциональный маршрут | Независимые этапы в допустимом порядке; зависимости нельзя обойти, номер сохраняется; врач подтверждает каждое перемещение |
| G03 | Исключения | Неявка, перенос/отмена МИС, конфликт версии, двойной вызов, сбой работника и повтор запроса не повреждают состояние |
| G04 | Безопасность | Реальный Keycloak/HTTPS, запрет доступа к чужому кабинету, отозванные устройства, журналы без избыточных данных; review и тесты ИБ |
| G05 | Сеть и устройства | 3 кабинета, общее табло и терминал; 48–72 ч на целевых SBC, отключение питания/Ethernet, stale warning, локальный звук, сканер, ручной режим |
| G06 | Производительность | Реальный профиль 50 табло/20 рабочих мест/5 терминалов или согласованный иной; нагрузка в течение смены. Предварительные цели p95 REST ≤200 мс, вызов→рендер ≤1 с, stale warning ≤15 с; фиксировать реальные значения |
| G07 | Наблюдаемость | Grafana/Prometheus на площадке, проверка метрик и alerts, маршрутизация уведомлений ответственному, отсутствие ПД/секретов |
| G08 | Восстановление | Резервный снимок, отдельная чистая БД, восстановление, сравнение целостности и сценариев; RPO/RTO измерены, согласованы и соблюдены |
| G09 | Интеграция | Официальный API/sandbox, данные и ответственность согласованы; повтор/отмена/смена кабинета подтверждены с поставщиком; нет произвольного доступа к БД МИС |
| G10 | Клинический процесс | Регламент очереди и маршрутов, исключения/неотложная помощь, доступ без смартфона, персонал знает ручной резервный процесс |
| G11 | Право/ИБ | Договорённости, допустимый состав данных, срок хранения, доступы, защита информации и правовые основания подтверждены ответственными |
| G12 | Эффект | Baseline и сопоставимая выборка, p50/p90 ожидания, время от входа до завершения, ручные вызовы, доступность; критерии согласованы до пилота |

**Stop:** любое нарушение G03/G04/G05/G08/G09/G10/G11, неподтверждённое использование реальных данных, невозможность безопасно вернуться к штатной работе. При нарушении цели G06 анализировать измеренные задержки, повторно тестировать. Решение о допуске принимает владелец клинического процесса вместе с ИТ/ИБ; разработчики не утверждают медицинские правила. Технический smoke и synthetic simulation сами по себе не подтверждают экономический эффект.

## Чек-лист протокола

- Git SHA и версии runtime/DB/браузера/устройства; схема сети; профиль нагрузки и длительность.
- Результаты CI (ссылки), логи без секретов, дата и ответственный.
- Baseline и сравнение, размер выборок, p50/p90/p95 и неопределённость.
- Инциденты, блокирующие замечания, план устранения, дата повторного теста.
- Согласованный ручной процесс и порядок остановки; решение go/no-go.
